HubSpot tracking property

Create a custom contact property in HubSpot:

Property name:   Forge Warm Reactivation 2026-05
Type:            Dropdown
Values:          Not Sent · Sent · Replied Interested · Replied No · No Reply 30d · Booked Call · Closed

Then create a HubSpot list filtered to "Forge Warm Reactivation 2026-05" = anything except Not Sent. This dashboard is the operating view; HubSpot is the system of record.
